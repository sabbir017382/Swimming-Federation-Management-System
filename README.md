# 🏊 Swimming Federation Management System

A full-stack web application developed using Spring Boot to manage swimming federation activities including player registration, event management, scheduling, and administrative operations.

This project demonstrates backend development skills using Java, Spring Boot, and database integration following layered architecture principles.

---

## 🚀 Technologies Used

- Java 17
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Thymeleaf
- HTML, CSS, Bootstrap

---

## 🎯 Key Features

- ✅ Player Registration & Management
- ✅ Event Creation & Scheduling
- ✅ Admin Dashboard
- ✅ CRUD Operations
- ✅ Form Validation
- ✅ Database Integration
- ✅ Layered Architecture (Controller → Service → Repository)
